Music Cosmos

Прототипы визуализации личной музыкальной библиотеки. Каждый файл открывается сам по себе — WebGL2, без сборки и зависимостей.

Основная линия

08
Живая карта реальные данные
Настоящая библиотека: 4334 трека, 1287 авторов, 39 жанров и эпох. Классика разложена по времени — от Средневековья к современности; в популярной нити протянуты между жанрами, которые делят исполнителей. Треки из чартов Replay светятся ярче. Есть поиск и карточка с фактами по любому телу.
07
Масштабы заглушки
Непрерывный зум сквозь четыре уровня: вселенная → сверхскопления (поп / классика) → галактики-жанры → системы-авторы → планеты-треки. Кадр не пустеет ни на одной высоте — счётчик в углу это показывает.
06
Формы и нити
Десять минеральных пород вместо шаров: друза кристаллов, гранёный шар, осколок, стопка плит, базальтовая глыба. Издалека — свечение, вблизи — форма. Между жанрами протянуты нити с бегущими импульсами.
05
Нырок: планета → статья
Переход от карты к тексту. Карта уходит, читаемая страница занимает экран. Три написанные статьи и пустое состояние.

Поиск направления

04
Пять концепций
Нейросеть, хорды, гребни, поток, созвездия — пять разных языков для одной библиотеки, каждый живой.
03
Статичный кадр
Шейдерная песочница: процедурный шум, слои, зум к курсору. Первая проба материала.
02
Творческое направление
Разбор того, какими средствами идею стоит делать — с живой туманностью в шапке.
01
Приоритеты ТЗ
Шесть ярусов работ, разложенных по спектральным классам звёзд: что делать первым и что не имеет под собой данных.

Инструменты

tools/ — разбор и правка XLSX через awk и PowerShell (без библиотек для таблиц) и извлечение текста из PDF без poppler. Тем же набором нормализованы 1923 ячейки листа Classical.

Прототип 08 построен на настоящей выгрузке библиотеки; в 01–07 данные процедурные — там проверялись геометрия и поведение, не содержание.
