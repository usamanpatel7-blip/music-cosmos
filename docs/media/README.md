# Голос фильма

Сюда кладутся два файла, которые сохраняет суфлёр фильма
(`index.html#film&author` → «записать голос»):

- `intro.webm` / `intro.m4a` / `intro.mp3` / `intro.ogg` — голос. Фильм
  пробует их в этом порядке: mp3, m4a, webm, ogg. Для Safari надёжнее mp3:
  `ffmpeg -i intro.webm -b:a 64k intro.mp3`.
- `intro-cues.js` — начало каждой фразы в секундах; по нему субтитры встают
  под голос.

Пока файлов нет, фильм идёт на одних субтитрах. Если голос записан в
другой программе, достаточно `intro.mp3`: субтитры растянутся по длине
записи.
