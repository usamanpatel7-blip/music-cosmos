# Извлечение данных из таблицы

```sh
python3 tools/extract/build.py            # → data/cosmos.json
```

Один запуск от книги до `cosmos.json`. Ни библиотек для xlsx, ни Node: книга —
обычный zip с XML, а листы находятся по имени через `workbook.xml`, а не по
номеру файла внутри архива, как в прежнем конвейере.

## Что собирается

Дерево: реалм → эпоха или жанр → направление или субжанр → *(деление, если
уровень слишком широк)* → композитор или исполнитель → произведение или альбом →
трек.

У трека выгружаются год, лучший ранг Replay и число периодов в чартах,
Apple ID, витрина и возрастные плейлисты владельца. Ссылка на Apple Music не
хранится: она собирается из идентификатора альбома и трека,
`music.apple.com/{витрина}/album/{альбом}?i={трек}` — так файл легче на 400 КБ.

## Словари

`subgenres.tsv` сводит составные ярлыки к каноническим. В выгрузке у «Рока»
54 субжанра, больше тридцати из них встречаются ровно по разу: «Британский
рок / поп-рок», «Хард-рок / хеви-метал», «Прогрессивный / арт-рок». После
сведения остаётся 27.

`epochs.tsv` — поправки к ярлыкам эпох: имя и границы. Составной ярлык вида
«Классицизм / ранний романтизм (1815–1910)» автоматике не поддаётся: по первой
половине выйдет «Классицизм» вместе с Гайдном и Моцартом, по второй — «Ранний
романтизм», а ранний романтизм это Шуберт, а не Бетховен. Бетховен — стык двух
эпох, и назван он должен быть стыком, поэтому решение записано руками:
«Классицизм → романтизм», 1790–1830. Границы 1815–1910 из таблицы к нему тоже
не относились — это рамки романтизма, а он писал с 1792 по 1827.

`names-ru.tsv` — написание русских исполнителей. Кандидаты найдены по коду
страны в ISRC: латиницей записаны ровно 63 исполнителя с российским или
украинским ISRC. Обратная транслитерация ненадёжна («Anton Batagov» машинно не
станет «Антоном Батаговым»), поэтому написание проставлено руками. Знак `=`
означает «оставить латиницу»: так пишется само имя — Oxxxymiron, Shortparis,
Intelligency. Большая часть списка — исполнители академической ветки, а на
карте там стоит композитор, поэтому в дереве они не появляются.

## Деление широких уровней

Узел, у которого больше `MAXLEVEL` детей (60), делится дальше. Порядок
делителей: десятилетие → пятилетие → алфавитный диапазон. Для произведений
композитора десятилетие не используется: в таблице год — это год записи, а не
сочинения, и деление по нему было бы враньём.

Алфавит смысла не несёт и нужен для случаев вроде собрания Баха на 156
произведений; в интерфейсе он и подписывается алфавитом, а не выдаётся за
осмысленное деление.

## Заметки

Файлы `notes/<тип>/<имя>.md` подхватываются сборкой и кладутся рядом с
сущностью. Имя файла — путь: `notes/эпоха/барокко.md`,
`notes/композитор/иоганн себастьян бах (1685–1750).md`. Первая строка —
заголовок, дальше свободный текст.

## Проверка

`build.py` печатает отчёт и **завершается ошибкой, если у какого-то узла
осталось больше `MAXLEVEL` детей**. Экспорт разбирается обратно `json.loads`
перед записью, поэтому сломанный файл до браузера не доедет.

## Прежний конвейер

`ss.awk`, `sheet.awk`, `dump.awk`, `rows.awk`, `gen.awk` — конвейер на awk,
которым собиралась первая версия карты. Оставлены как история; `build.py` их
заменяет.
