# Стартовый экран: текст на правку

Здесь весь текст, который человек видит до того, как что-то нажал.
Сначала — что там сейчас, потом — что с этим не так, потом — вариант
на замену. Правьте прямо в третьем разделе, я перенесу.

---

## 1. Что там сейчас, дословно

```
личная музыкальная библиотека
Библиотека
4334 записей · 1220 авторов · 22 эпох и жанров · издания 1926–2026

[ найти трек, автора, произведение…            ] [ Смотреть ]

[Барокко 415] [Бах 206] [Мои шестнадцать 469] [Только Replay 587]
[Шестидесятые 273] [Случайная запись] [Вся библиотека 4334]

Клик по карте ведёт внутрь: солнце — автор, планета — запись. Пилюля
слева перебирает три фигуры: кольца, орбиты и ленту лет. Колесо и кнопки
справа приближают, тяга двигает. Точка слева от названия включает звук,
клавиша F отдаёт фигуре весь экран.
Или прочитайте музыкальный портрет: что эти четыре тысячи записей
говорят о слушателе.
```

---

## 2. Что с этим не так

**Заголовок и надзаголовок говорят одно и то же дважды.** «Личная
музыкальная библиотека» и «Библиотека» — это одна мысль, набранная
двумя кеглями.

**Строка чисел — это паспорт, а не повод.** «4334 записей, 1220
авторов» отвечает на вопрос «сколько», которого никто не задавал.
Числа тут нужны, но другие: не размер, а что-нибудь неожиданное.
Заодно «22 эпох и жанров» теперь просто неправда — эпохи и жанры
разведены, их 12 и 10.

**Подсказка объясняет прибор, который ещё не захотели включать.**
Четыре предложения про колесо, тягу, пилюлю и клавишу F стоят там,
где у человека ещё нет ни одной причины что-то трогать. Механику
лучше показывать в тот момент, когда до неё дошли, — и она уже
показана: подпись под кнопками теперь говорит, что нарисовано.

**Двери выбраны наугад.** Почему Барокко, а не Романтизм, которого
больше? Почему Бах, а не Моцарт? «Случайная запись» и «Вся
библиотека» — вообще не двери, а кнопки, и стоят в одном ряду с ними.

**«Смотреть» — слабый глагол** рядом с полем, в которое ещё ничего
не вписали.

## 3. Вариант на замену — правьте здесь

### Надзаголовок
```
четыре тысячи записей, разложенных руками
```

### Заголовок
```
Библиотека
```
*(варианты, если «Библиотека» кажется пресным: «Каталог», «Всё, что
слушалось», «Опись». Отдельное название сайта вы отложили — здесь
только заголовок экрана.)*

### Строка под заголовком
Вместо паспорта — три факта, из которых видно, что тут разбирались
руками, а не выгрузили таблицу:

```
2403 академические записи и 1931 повседневная · восемь полок от
одиннадцати лет до сегодня · 4280 записей стоят ровно на одной
```

*Последнее число — самое интересное из всех: из 4334 записей только
35 пережили переход с одной полки на другую. Остальные ушли вместе с
возрастом.*

### Поле поиска
```
плейсхолдер: найти запись, автора, произведение…
кнопка:      Искать
```

### Двери
Сейчас их семь и они про объём. Предлагаю пять, и каждая — про что-то,
чего человек не ожидает. Числа настоящие, считаются на лету.

```
[ Тридцать пять исключений        35   ]  единственные записи, которые
                                          пережили смену возраста
[ Шопен, шесть полок из восьми    96   ]  автор, с которым дольше всех
[ Что осталось с одиннадцати лет  104  ]  самая старая полка
[ Год, когда всё изменилось      1471  ]  полка «22–24 года»
[ Только Replay                   587  ]  то, что дошло до чартов
```

Плюс две кнопки отдельно, не в ряду дверей:
```
[ Наугад ]   [ Вся библиотека 4334 ]
```

### Нижняя строка
Вместо инструкции — одно предложение и ссылка:

```
Каталог звучит: точка слева от названия включает превью.
Или прочитайте музыкальный портрет — что эти записи говорят о слушателе.
```
